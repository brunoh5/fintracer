# Fintracer

**Sistema de gestão para oficinas mecânicas.**

O Fintracer é um sistema desenvolvido para simplificar a gestão de oficinas mecânicas, centralizando informações de clientes, veículos, ordens de serviço e operações do dia a dia em uma única plataforma.

O projeto está passando por uma reconstrução completa, com foco em uma arquitetura organizada, código sustentável, integridade dos dados e uma experiência de uso simples e eficiente.

## Objetivos

- Centralizar o cadastro e o gerenciamento de clientes e veículos.
- Facilitar a criação e o acompanhamento de ordens de serviço.
- Organizar serviços, peças, produtos e seus respectivos valores.
- Registrar pagamentos e acompanhar os valores das ordens de serviço.
- Reduzir tarefas manuais e facilitar o acesso às informações da oficina.
- Construir uma base sólida para futuras funcionalidades de gestão.

## Arquitetura e tecnologias

O Fintracer está sendo reconstruído com uma separação entre backend e frontend, permitindo que cada parte tenha responsabilidades bem definidas.

### Backend

O backend será desenvolvido manualmente, com foco no aprendizado, na compreensão dos fundamentos e no controle sobre as decisões de arquitetura.

Os principais objetivos técnicos são:

- APIs bem estruturadas e com responsabilidades claras.
- Modelagem relacional e consultas SQL explícitas.
- Integridade dos dados e controle das operações no banco.
- Validação de entradas e tratamento consistente de erros.
- Testes automatizados e facilidade de manutenção.

### Frontend

O frontend será desenvolvido com auxílio do Codex, da OpenAI, utilizando ferramentas de desenvolvimento assistido por IA para acelerar a implementação da interface.

O foco será construir uma aplicação responsiva, consistente e intuitiva, mantendo uma integração clara com a API.

### Princípios do projeto

- Simplicidade antes de complexidade desnecessária.
- Separação de responsabilidades.
- Código legível e sustentável.
- Segurança e integridade dos dados.
- Evolução incremental baseada nas necessidades reais das oficinas.
