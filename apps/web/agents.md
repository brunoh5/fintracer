
# Frontend Instructions

## Technology
- Follow the versions and dependencies already installed.
- Reuse the existing React, Tailwind CSS, and shadcn/ui setup.
- Follow the project's existing form and data-fetching patterns.

## UI and components
- Inspect existing components before creating new ones.
- Keep components small and reusable when appropriate.
- Maintain consistency with the existing design system.
- Support loading, error, empty, and success states.
- Ensure responsive layouts and accessible interactions.

## API integration
- Use the existing API client and authentication flow.
- Follow existing request, response, and error-handling patterns.
- Do not implement business rules that belong to the backend.
- Do not introduce mock data into production flows.

## Validation
- Run the frontend checks available in this package.
- Do not modify backend code to fix frontend failures.
